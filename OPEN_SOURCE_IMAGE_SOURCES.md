# Jaunpur Tourism Image Sources

The tourism cards use direct public image URLs from Wikimedia Commons so the portal can display the place-specific image while preserving a source/reference link.

- Atala Masjid — https://commons.wikimedia.org/wiki/File:Atala_Masjid_Jaunpur.JPG
- Shahi Bridge — https://commons.wikimedia.org/wiki/File:Shahi_bridge.jpg
- Jama Masjid, Jaunpur — https://commons.wikimedia.org/wiki/File:Jaunpur_Jama_Masjid.jpg
- Lal Darwaza Masjid — https://commons.wikimedia.org/wiki/File:Lal_Darwaza_Masjid_01.jpg

The portal shows an “Open-source image / reference” link on each card. Check the individual Wikimedia Commons page for the exact author and license/attribution terms before public redistribution.
